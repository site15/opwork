## Introduction

Vue Vben Admin is an upgraded version of Vue Vben Admin. As a free and open-source backend template, it is developed using the latest mainstream technologies such as Vue 3, Vite, and TypeScript. It is ready to use for backend frontend development and suitable for learning and reference.

## Upgrade Notice

This version is the latest version `5.0`, which is incompatible with other versions. If you are starting a new project, it is recommended to use the latest version. If you want to check the old version, please use the [v2 branch](https://github.com/vbenjs/vue-vben-admin/tree/v2)

## Features

- **Latest Tech Stack**: Developed using cutting-edge front-end technologies such as Vue3/Vite
- **TypeScript**: Language for application-level JavaScript
- **Themes**: Provides multiple theme colors, customizable themes configurable
- **Internationalization**: Built-in comprehensive internationalization solution
- **Permissions**: Built-in dynamic routing permission generation solution

## Installation and Usage

1. Get the project code

```bash
git clone https://github.com/vbenjs/vue-vben-admin.git
```

2. Install dependencies

```bash
cd vue-vben-admin
npm i -g corepack
pnpm install
```

3. Run

```bash
pnpm dev
```

4. Build

```bash
pnpm build
```

## How to Contribute

Welcome to join! [Submit an Issue](https://github.com/anncwb/vue-vben-admin/issues/new/choose) or submit a Pull Request.

**Pull Request Process:**

1. Fork the code
2. Create your own branch: `git checkout -b feature/xxxx`
3. Submit your changes: `git commit -am 'feat(function): add xxxxx'`
4. Push your branch: `git push origin feature/xxxx`
5. Submit `pull request`

## Git Contribution Submission Convention

Refer to [vue](https://github.com/vuejs/vue/blob/dev/.github/COMMIT_CONVENTION.md) convention ([Angular](https://github.com/conventional-changelog/conventional-changelog/tree/master/packages/conventional-changelog-angular))

- `feat` Add new features
- `fix` Fix issues/bugs
- `style` Code style related without affecting running results
- `perf` Optimization/performance improvement
- `refactor` Refactoring
- `revert` Revert changes
- `test` Test related
- `docs` Documentation/comments
- `chore` Dependency updates/framework configuration modifications, etc.
- `ci` Continuous Integration
- `types` Type definition file changes
